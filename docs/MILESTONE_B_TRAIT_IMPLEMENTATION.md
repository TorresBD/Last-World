# Milestone B: trait and mandatory-biology implementation audit

Audit date: 2026-10-30. This is a read-only code-to-catalogue review of a changing working tree, not a release certificate. No tests, compiler, GPU run or PC interaction test were executed for this audit. Test names below identify assertions present in source; they do **not** say the latest combined suite passed. Earlier component results do not qualify later campaign edits. The primary agent owns the current combined results, STATE and PARITY.

The source of scope is the supplied Complete Game and Ecology Development Prompt sections4–6 and Appendix A, the selected30 in `MILESTONE_A_TRAIT_PROPOSAL.md`, and `MILESTONE_B_ACCEPTANCE.md`. All30 IDs match `ecology::SELECTED_TRAITS`; the other130 remain future scope. Mandatory biology is additional to these30. The resident campaign currently covers4.8×3.2km; the target20×20km streamed world is not established by these mechanisms.

## Current truth and priority gaps

All30 IDs have executable code paths or supporting mechanisms. That is weaker than saying every intended world interaction is complete. The following integration gaps were found and sent to the primary agent immediately:

1. Biological roots do not yet update `GroundCell.root_strength_permille`: it is initialized from original visual cover. Consequently loss/recovery of living roots currently does not change erosion resistance. Soil-mixing porosity is owned and conserved in `PhysicalPatch`, but has no current ground-infiltration projection. Required ground-condition setters/projection are being coordinated separately; do not count them complete merely because a field exists.
2. `HabitatWorld::destroy_host` has finite debris/fall/cavity/clutch behavior and tests, but at the initial audit snapshot no live campaign bridge called it when biological canopy support disappeared. One aggregate host reference represents each macro patch; it is not an individually simulated tree. A coupling fix has been assigned to the physical-habitat owner. Its honest minimum resolution is support loss when actual supporting canopy biomass reaches zero, not per-tree precision.
3. Weather changes rain, temperatures, water depths and biological availability. The initial snapshot has no moist-ground traction/mud cost in `NavCell` or movement cost; moisture without standing-water/cover changes does not slow a soldier. Seasonal/wallow traction is therefore not satisfied by the climate fields alone.
4. Mandatory temperament/social fields (`docile`, `social_group_size`, `territorial_radius_m`, `threat_response`) were generated and saved but had no behavior consumers in the initial snapshot. The ecology owner has been notified. A test asserting that a flag was generated does not establish its gameplay effect.
5. Baseline diet/reproduction is narrower than the supplied schema: explicit preferred/fallback nutrition, omnivory and retained-egg/spawning modes are absent in the initial snapshot. The current enum supports seeds, spores, eggs and live birth. Do not label the entire required animal schema complete.
6. Wild den/nest reproduction checks patch-level shelter capacity, while physical occupancy is individual and finite. Multiple wild cohorts can pass the same aggregate capacity predicate without each owning a specific reachable reproductive shelter. Captive pen capacity is separately reserved and tested. This distinction needs a coupled wild breeding/capacity check.
7. Macro animal migration uses available border-crossing masks, not an internal path from every animal location to that crossing. Existing in-flight transits are checked for destination habitat suitability, but not revalidated against all newly closed route edges before arrival. Actual worksite travel has a bounded local path; it does not fix every macro migration path automatically.
8. Dynamic hydraulic storage/flow is confined to the managed river region. The rest of this resident map has coarse/static water-depth conditions. A dam outside the managed region is rejected instead of pretending to pool water. Underground water is an entrance-connected flood-hazard projection, not a second volumetric fluid simulation.

These are qualification boundaries and actionable gaps, not permission to remove required effects. Update this document after the fixes and their checks exist. A final B decision must use the current integrated build and necessary native-PC evidence.

### Integration changes landed after the initial findings

The following source changes became visible during this audit. **Their current combined tests remain pending**; the initial findings above remain the record of why they were needed, rather than a claim these specific gaps are still unaddressed in code.

- `Ecology::root_reinforcement_permille`, `Campaign::update_ground_conditions`, `GroundModel::set_biological_conditions` and `set_substrate_porosity` now project current living roots/cover/canopy and actual upper-layer porosity into managed-river erosion, infiltration and shade-sensitive water loss. Named source tests: `current_root_and_cover_loss_changes_erosion_without_moving_stocks_on_assignment`, `live_cover_roots_and_canopy_change_actual_infiltration_and_evaporation_conservatively`. Interception/rain redistribution and sediment-carried biological seed/litter are still distinct, unimplemented couplings.
- `NavCell::soil_moisture_permille`, `traction_band` and movement/path-cost changes now make wet ground slower and limit the road mud penalty. Named source tests: `wet_soil_reduces_offroad_traction_while_roads_limit_the_mud_cost`, `soil_moisture_updates_only_revise_route_cost_when_a_traction_band_changes`.
- `EcosystemPhysics::synchronize_hosts` now connects actual living trait157 canopy shoot/leaf stock to the existing aggregate host. At zero supporting tissue, real host destruction releases occupants, applies finite fall injury (flying animals can land), destroys exact surviving attached clutches once, and transfers already built nest material to debris without a second standing-biomass debit. Partial thinning retains the aggregate support. Real regrowth can restore canopy support; old destroyed nests/cavities/clutches remain destroyed. It runs before and after engineering and is available for immediate campaign blast/clearance handoff. Named source test: `actual_canopy_loss_collapses_cavity_and_paid_nest_once_without_new_biomass`. Per-tree precision is still outside this aggregate representation.
- `Cohort::breeding_refuge`, `Ecology::set_breeding_refuge` and `EcosystemPhysics::synchronize_breeding_refuges` now replace aggregate wild den/nest eligibility with exact individual reservations. The builder owns its paid nest, real den occupancy supplies only that occupant's reserved slots, and each existing clutch attaches to its actual mother's owned nest. Compatible64+65 animals can build a material-funded nest inside an accessible occupied den room, including paid entrance-route material collection. Builder and offspring share the same finite paid chamber slots; a nested Nest does not add a second room. `HabitatWorld::attach_clutch` and room travel now include actual nested eggs in room occupancy. Named source test: `paid_nested_nest_and_exact_mother_claim_share_real_den_capacity`. Ordinary surface acquisition is still a finite patch-source model, and underground travel charges actual graph length without interpolating each underground step as a visual individual.
- `ecology_behavior::handling_ticks`, `movement_pressure` and `destination_bias` now consume docility, body mass, threat response, actual regional conspecific counts, group preferences and territorial footprint. `Ecology::capture_work_ticks` is used by the real campaign handler's accumulated work counter. Ordinary food/habitat eligibility and paid transit still own movement; utility scores do not clamp populations. `Ecology::alert_threat` supplies persisted finite threat duration. Named source tests: `docile_handling_pays_real_time_but_less_than_identical_wild_animal`, `observed_threats_change_response_without_making_defensive_animals_immune`, `projected_group_size_and_territory_change_destination_ranking`. These are coarse decisions, not a complete fine combat/defense AI; proper native handler interaction still needs its integrated check.

## Shared ownership and scheduling

`Ecology` owns animal/cohort identities, plant patches, food, reproductive tickets, body/reserve material, biological water and deaths. `HabitatWorld` owns sparse physical geometry, finite occupancy references and built material; it never owns a second animal. `EcosystemPhysics` owns finite underground substrate, two soil-mixing layers, mineral sources, work queues and engineering wallets. `Terrain`/`GroundModel` own surface cut/fill and soil/sediment; `WaterGraph` owns surface liters and fluxes. Navigation and rendering derive conditions rather than minting stocks.

The20Hz action clock does not run ecology every rendered frame. Ecology/physical integration processes each due20-tick interval; engineering intents are proposed on a200-tick cadence. At most four engineering jobs are active. Work is funded only by elapsed awake/living time at a reachable stand-site, plus finite energy/stamina. Travel ticks do not become building ticks. Source cohorts are materialized exactly once for individual physical work, with actual species body width. Construction can wait or fail for lack of material, time, space or access; it does not silently create resources.

Engineering uses prepared habitat transactions and source preflight. Harvested wood/fiber leaves `Ecology::export_biomass` once; it is not simultaneously standing biomass, litter and timber. Underground excavation removes finite underground substrate and produces spoil without lowering the entire surface. Fine pit/wallow excavation retains the sub-geometry residual so millimeter terrain quantization neither destroys nor invents soil. The sparse maps and pending routes survive serialization.

Trait flags use five32-bit words for160 independent flags. Numeric profiles, prerequisites, partners, delays and reserves remain separate. This corrects the earlier impossible assumption that160 independent booleans fit losslessly into128bits. Current ecology executes on the CPU; the existence of bitmasks does not establish GPU ecology compute or zero-copy mutation.
