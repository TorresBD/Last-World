# Last World pixel-map icons

Six style anchors: road, trench, depot, camera tower, builder, mine.
Hand-plotted character grids, 1px dark outline, top-left lighting, three tones per material. One shared palette of twelve entries including transparency; amber/blue are reserved faction accents. Each 32px grid is an exact twofold pixel plotting of its 16px source, with no smoothing. Native rendering uses integer nearest-neighbour copies. No routine preview images are generated.

The manifest contains stable IDs, labels, hotkeys, versions, note IDs and silhouette descriptions. Camera silhouettes distinguish a field tripod, narrow pole, braced tower and wall bracket. Troops share an outlined body with separate equipment. Show IDs is a dev preference; notes go in NOTES.md. Run native/scripts/check-ui-icons.py for data checks.
