# Last World

Native Rust/Bevy/wgpu ecological RTS for Windows PC; Milestone B is in development.

Start with [project/MASTER.md](project/MASTER.md) for current scope, rules, state and the active opening/HUD task. Search [project/LEDGER.md](project/LEDGER.md) by ID/tag for decisions and builds.

- [native/README.md](native/README.md): build, play and check instructions.
- `docs/`: detailed designs and qualification methods.
- `evidence/`: dated test and PC evidence.
- [project/archive/README.md](project/archive/README.md): frozen historical handoffs and the legacy-record location map.

The former root RULES/STATE/DECISIONS/BLOCKERS/PARITY files are superseded and removed. Their full text remains in the indexed archived handoff. The previous browser README is retained there as historical reference. Keep Master and Ledger in `project/` in all future source versions.
